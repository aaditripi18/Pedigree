Pedigree: do models come from where they say they do?

A model card's base_model tells licence checks, procurement reviews and the Hub what a model is built on. Nobody checks it. Pedigree checks it from the weights, on a frozen random sample of the Hub, with a verifier measured on ground truth first.

Hypotheses

Every decision rule was committed in PLAN.md before the runs it governs; verdicts are never reworded. The last column repeats each verdict under a second threshold rule.

Check a model yourself

The browser checker runs the same comparison in this page, reading only file headers and small slices of tensors from the Hub. The CLI does the same for PyTorch, GGUF and MLX files too:

pip install git+https://github.com/aaditripi18/Pedigree
pedigree verify hf:org/model --base hf:org/base
